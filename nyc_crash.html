Introduction

This analysis uses NYC motor vehicle collision data to demonstrate how SHAP can help explain a machine learning model. I use an XGBoost model to predict whether a crash resulted in an injury and then use SHAP to examine which features influenced the model’s predictions.

2. Create the Injury Variable

I created a binary variable called injury. A value of 1 means that at least one person was injured in the crash, while 0 means that no injuries were reported.

crashes <- crashes %>%

4. Split the Data

I used 80% of the observations for training and 20% for testing.

set.seed(123)

split <- sample(
  seq_len(nrow(model_data)),
  size = 0.8 * nrow(model_data)
)

train_data <- model_data[split, ]
test_data <- model_data[-split, ]

5. Prepare Data for XGBoost

The categorical variables need to be converted into numeric dummy variables before they can be used by XGBoost.

x_train <- model.matrix(injury ~ . - 1, data = train_data)
x_test <- model.matrix(injury ~ . - 1, data = test_data)

y_train <- as.numeric(train_data$injury) - 1
y_test <- as.numeric(test_data$injury) - 1

6. Train the XGBoost Model

I trained an XGBoost model using the training data and generated predictions for the test data.

model <- xgboost(
  x = x_train,
  y = factor(y_train),
  nrounds = 100
)

predictions <- predict(model, x_test)

head(predictions)

7. Evaluate the Model

Predicted probabilities above 0.5 were classified as injury predictions.

results <- tibble(
  actual = y_test,
  predicted = if_else(predictions > 0.5, 1, 0)
)

results %>%
  summarise(
    accuracy = mean(actual == predicted)
  )
# A tibble: 1 × 1
  accuracy
     <dbl>
1    0.706

The model achieved approximately 68% accuracy on the test data. The purpose of this analysis is not to optimize prediction accuracy, but to demonstrate how SHAP can be used to interpret a machine learning model.

8. Calculate SHAP Values

SHAP values were calculated for the observations in the test dataset.

shap_values <- predict(
  model,
  x_test,
  type = "contrib"
)

shap_matrix <- shap_values[, -ncol(shap_values)]
colnames(shap_matrix) <- colnames(x_test)

shap <- shapviz(
  shap_matrix,
  X = x_test
)

9. Overall Feature Importance

The SHAP importance plot shows which features had the largest influence on the model’s predictions overall

sv_importance(shap)

In this model, hour of the crash was the most important feature overall. Several contributing factors, borough indicators, and vehicle types were also important.

10. Explain One High-Risk Prediction

I selected the observation with the highest predicted probability of injury.

high_risk <- which.max(predictions)

For this observation, the model predicted a very high probability of injury, and the actual outcome was also an injury. The waterfall plot shows that bike involvement and the hour of the crash were two of the strongest positive contributors to this prediction.

Summary

This example demonstrates the difference between prediction and explanation. XGBoost produced the injury prediction, while SHAP helped show which features the model relied on when making that prediction.

SHAP explains model behavior, not causation. A high SHAP value for a feature does not mean that the feature caused the injury; it means that the feature influenced the model’s prediction.
